Guía rápida

 
variable nombre = "Alex" — crear variable
si condicion { }, sinosi, sino — condiciones

 
funcion saludar(nombre) { } — función
retornar valor — devolver valor

 
mientras condicion { } — bucle
para variable i = 1 hasta 5 { } — bucle contado

 
romper — salir del bucle; continuar — saltar repetición
hacer { } mientras condicion — repetir al menos una vez

 
esperar(5) — esperar 5 segundos antes de continuar
mostrar(valor) — escribir en consola

 
Con comillas, mostrar("5+5") imprime el texto. Sin comillas, mostrar(5+5) imprime 10.
